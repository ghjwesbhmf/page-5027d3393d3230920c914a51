使用场景

流媒体与内容访问

旗舰版与团队版强调全节点原生解锁，便于在电视、平板或电脑上打开常见视频与音乐服务。基础版覆盖基础流媒体，高峰时段建议优先选择邻近地区节点以降低缓冲。

游戏与实时对战

对延迟敏感的用户可使用旗舰档 IPLC 专线游戏加速优化，将游戏流量与普通网页分流。连接后在客户端中固定游戏相关进程走加速节点，减少抖动。

远程办公与资料同步

文档协作、代码仓库与云盘同步依赖稳定上行。团队版提供更高带宽节点与定制路由，可按域名将办公应用走专线，其余流量保持直连。

多设备随身使用

同一订阅可导入手机、电脑与路由器（受套餐设备数限制）。出差时用移动客户端，回家后用电脑客户端，互不影响在线配额内的使用。

客户端选择

八度加速以通用订阅链接对接主流内核，不绑定单一封闭 App。选择客户端时，先确认系统，再确认是否需要规则分流与 TUN 模式。以下为官方推荐路径，下载入口见后文「官方下载」。

Windows / macOS 电脑

优先 Clash Meta 系图形客户端或 sing-box 桌面端：导入订阅后可按规则分流、选择节点、查看延迟。需要系统级接管流量时开启 TUN。若只需浏览器访问，也可仅对浏览器使用系统代理。

Android

推荐 Clash Meta for Android 或兼容 sing-box 的客户端。导入八度加速订阅后，建议开启分应用代理，让游戏与视频走加速，国内应用直连，节省套餐流量。

iOS / iPadOS

常用 Shadowrocket、Stash、Quantumult X 或 Surge。App Store 安装完成后粘贴订阅 URL，开启 extra UDP 与正确的 DNS。企业或家庭共享设备时注意不要超出同时在线台数。

路由器与软路由

OpenWrt、iStoreOS 等可运行 Clash / sing-box 的环境，适合全家设备共享一个额度。团队版更适合这种部署。请将路由器计为 1 台在线设备，并避免再在终端重复拨号导致超限。

操作说明

按纵向步骤完成开通即可上网。全程在八度加速官网账户与所选客户端内操作，无需第三方破解包。

步骤 1：选择套餐

根据流量、设备数与是否需要 IPLC、原生流媒体，在基础版、旗舰版或团队版中选定月付或年付。

步骤 2：获取机场订阅

开通后在用户中心复制通用订阅链接。该链接用于 Clash 等客户端定期拉取节点与流量信息，请勿公开传播。

步骤 3：下载对应客户端

打开本页「官方下载」锚点，按系统选择 Clash Meta、Shadowrocket、sing-box 等工具。仅从正规应用商店或本站标明的官方渠道安装。

步骤 4：导入配置并测速

客户端内选择「从 URL 更新」。完成后对香港、日本、新加坡、美国等入口做延迟测试，剔除超时节点，收藏两条备用线路。

步骤 5：连接与分流

开启系统代理或 VPN/TUN。将视频、会议、游戏走代理，国内银行与政务类应用直连。确认连接成功后再进行大流量传输。

常见问题

八度加速是什么？和普通 VPN 有何不同？

八度加速是提供机场订阅的网络加速服务：你获得的是可导入 Clash 等客户端的节点列表与流量配额，而不是单一封闭 App。这样可以自由选择客户端、自定义分流规则，并按套餐使用香港、日本、美国等线路，兼顾梯子访问、流媒体与游戏加速。

如何从官网完成客户端下载并开始使用？

先在本页选定套餐并复制订阅链接，再根据系统到应用商店或对应项目官方渠道安装客户端，最后在客户端内粘贴订阅 URL 更新。电脑建议 Clash Meta，手机按 iOS 或 Android 选择。完整顺序见「操作说明」五步。

基础版、旗舰版和团队版该怎么选？

轻度网页与 3 台以内设备选基础版（100GB）。需要原生流媒体、IPLC 游戏优化和优先工单选旗舰版（300GB、5 台设备）。超过 5 台、需要定制路由或专属经理时选团队版（1000GB、20 台）。年付价格已在各档标明。

流量如何计算？看视频会不会很快用完？

流量按实际代理出口计量，含上下行。高清视频与大文件同步消耗明显，4K 直播尤其快。基础版适合点播与文档；长期追剧请选旗舰或团队档，并在客户端对国内站点直连，避免无谓走代理。

多设备同时在线超限会怎样？

超过套餐台数后，新设备可能无法握手或旧会话被挤下线。路由器共享计为 1 台。建议在客户端退出不用的配置文件，或升级到旗舰版、团队版以获得 5 台与 20 台额度。

节点包含哪些地区？IPLC 有什么用？

常规节点池覆盖常用亚太与北美入口，具体列表以订阅更新为准。IPLC 专线主要用于降低游戏与实时音视频的抖动，是旗舰版写明的优化能力，不替代所有普通线路。观看流媒体时优先选标注原生解锁的节点。

年付是否更划算？会不会自动扣费？

三档均给出年付价：基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年，相当于月付十个月左右的价格。是否自动续费以结算页提示为准；建议在到期前关注配额，避免订阅失效导致客户端拉空节点。
